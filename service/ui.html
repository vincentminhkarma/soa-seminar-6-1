Một yêu cầu. Một dịch vụ AI.

Tích hợp OpenAI API vào một dịch vụ: client gọi qua hợp đồng REST, service gọi gateway tương thích OpenAI bằng Chat Completion, Function Calling và Prompt Engineering.

01Kết nối gateway

Nhập endpoint, tải danh sách model rồi chọn model. Cấu hình chỉ nhận từ máy này, key giữ trong RAM.

02Phía client: gọi dịch vụ

Client chỉ biết hợp đồng REST: gửi raw_text và mode, nhận JSON. Đổi cách xử lý bên trong không bắt client đổi theo.

Yêu cầu

POST /api/v1/extract-booking

Đối chứng bằng quy tắc cố định. Không cần key, không sử dụng token.

Dữ liệu giả lập, không tạo booking thật. Gateway có thể tính phí; qua ngrok chỉ dùng regex.
